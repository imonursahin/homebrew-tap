# Homebrew Tap

Install [Archo](https://github.com/imonursahin/archo):

```bash
brew install --cask imonursahin/tap/archo
```

Install [Kokpit](https://github.com/imonursahin/kokpit):

```bash
brew install --cask imonursahin/tap/kokpit
```

Install [Review Radar](https://github.com/imonursahin/review-radar):

```bash
brew install --cask imonursahin/tap/review-radar
```

The casks strip the quarantine flag on install, so the apps open normally even
though they are unsigned.
